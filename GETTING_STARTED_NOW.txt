📱 选项 2: 手动操作（3 步完成）

    步骤 1: 合并 Pull Request
    ├─ 访问: https://github.com/luojizhihen/zfm_team_web/pulls
    ├─ 找到部署相关的 PR
    └─ 点击 "Merge pull request" → "Confirm merge"

    步骤 2: 启用 GitHub Pages ⚠️ 重要
    ├─ 访问: https://github.com/luojizhihen/zfm_team_web/settings/pages
    ├─ 找到 "Build and deployment" 部分
    ├─ 在 "Source" 下拉菜单中选择
    └─ ✅ 选择 "GitHub Actions"（不是 "Deploy from a branch"）

    步骤 3: 等待部署完成
    ├─ 访问: https://github.com/luojizhihen/zfm_team_web/actions
    ├─ 查看 "Deploy to GitHub Pages" 工作流
    └─ 等待显示绿色 ✓（约 2-5 分钟）

    ⏱️  预计时间：5-8 分钟
    🎓 技能要求：基本浏览器操作
